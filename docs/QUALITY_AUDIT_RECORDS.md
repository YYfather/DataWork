# DataWork 0.4.4 ANOVA、MANOVA 与因素组合专项验证

## 分析目的

核对单因素、双因素、三因素 ANOVA 和 MANOVA 的变量定义、模型公式、交互后续分析、EMM 参数传递及超额因素组合行为，确保界面、分析计划、预检、统计执行器和报告一致。

## 预期效果（Expected Outcome）

- MANOVA 的“多元”始终表示至少两个联合因变量；
- 普通单次模型严格使用方法定义的因素数量；
- 超额因素默认不执行，必须由用户确认后才展开组合；
- 显著交互优先进入校正后的条件简单效应；
- 组合任务数、组合内容和跨任务校正可在执行前审查。

## 修复内容

### 联合因变量

MANOVA 注册表维持 `dependent_mode=joint`、最少两个因变量。即时分析和项目工作区切换到 MANOVA 后会从候选数值列中自动补足至少两个，并将角色显示为“联合因变量”。执行公式保持：

```text
Y1 + Y2 + ... ~ A * B * C
```

多个因变量不会被拆成多个独立 ANOVA。

### 因素组合确认

组合模式默认关闭。达到方法正常因素上限后继续点击因素，会弹出明确确认窗口；取消时不加入，确认后才进入组合模式。

| 方法 | 单次模型因素数 | 选择 n 个候选因素后的默认任务 |
|---|---:|---:|
| 单因素 ANOVA / Welch / Kruskal 等 | 1 | `C(n,1)` |
| 双因素 ANOVA | 2 | `C(n,2)` |
| 三因素 ANOVA | 3 | `C(n,3)` |
| MANOVA | 1–3 | 超过 3 个时默认 `C(n,3)` |

每个组合是独立模型，不是包含全部候选因素的超阶模型。预检显示模型数、组合阶数、每个任务的可执行性及跨任务 p 值校正。

### 交互后续分析

双因素、三因素 ANOVA 和 MANOVA 的单变量跟进统一执行以下规则：

1. 识别显著的最高阶交互；
2. 停止涉及因素的边际主效应自动比较；
3. 在条件水平组合内拟合简单效应模型；
4. 对简单效应 p 值统一应用 Holm、Bonferroni、Šidák、FDR-BH 或不校正；
5. 仅对校正后显著的简单效应执行条件内 EMM 成对比较。

### MANOVA 诊断

- Bartlett 探索性检验改为完整模型残差相关矩阵；
- 因变量条件数改为标准化矩阵计算，避免单位尺度误报；
- Box's M 使用独立阈值，默认 0.001；
- Mardia 继续使用模型残差；
- 用户指定 EMM、EMM 因素和对比校正实际传入每个单变量跟进模型。

### Dunnett

支持统一对照值：

```text
CK
```

也支持按因素分别指定：

```text
处理=CK;品种=对照品种
```

模型 EMM 场景下明确标记为 Dunnett 型、Bonferroni 保守近似；单因素原始组数据仍可使用 SciPy 单步 Dunnett。

- 集成、API、桌面外壳和工作区测试：35 项通过；
- 高级参数、AI、分类组合、退化数据、扩展方法及本版本专项测试：39 项通过；

- 209 组注册高级参数变体按方法分区实际执行通过；

## 统计边界

- 普通 MANOVA 仍是对象间固定效应多响应模型，不是多响应混合效应模型；

## 5. ANOVA 与 MANOVA 解释核对

“连续因变量”不是一种特殊于 MANOVA 的新因变量，而是可以在数值尺度上进行均值、方差和线性组合运算的响应变量，例如身高、产量、评分和浓度。“因变量”是更宽泛的角色名称：它可以是连续、二元、名义多分类或有序分类；类型不同决定应使用 ANOVA/线性模型、Logistic 模型还是列联表方法。

- 单/双/三因素 ANOVA：一个连续因变量，分别由一个、两个或三个分类因素解释；最高阶交互优先解读。
- 单/双/三因素 MANOVA：至少两个连续因变量作为联合响应，一次检验因素对其线性组合的整体影响；先报告多变量判据，再做经多重校正的单变量跟进。
- 总分若由其他因变量精确相加得到，与组成分数同时进入 MANOVA 会产生线性依赖，应删除冗余响应或只把总分作为描述性派生指标。
- DataWork 普通模式默认 Pillai 轨迹，专业模式保留 Wilks、Hotelling-Lawley 和 Roy；这是稳健性选择，不改变底层四种判据的计算。

## 6. 规范报告规则

参考 `参考基准/来自分享的对话.md`，附加报告采用“研究目的与设计 -> 假设和诊断 -> 总体检验 -> 后续分析 -> 效应量与不确定性 -> 结论与限制”的顺序，并执行以下约束：

1. 双/三因素模型先报告最高阶交互；显著时优先简单效应或简单-简单效应，不脱离交互概括被修饰的主效应。
2. MANOVA 先报告多变量判据，再报告校正后的单变量跟进和条件比较。
3. 优先使用校正后 p 值，同时报告校正方法、效应量和已有置信区间。
4. `p >= alpha` 只表述为“证据不足/未达到显著”，不写成“完全相同”或“因素相互独立”。
5. 不把观察性关联写成因果，不从未显著结果推导等效性。

参考对话中的示例数字不会进入提示词或结果；其中“Tukey 仅适用于等样本量”“总体检验不显著时任何预先计划比较都无意义”“交互不显著即因素相互独立”等过强说法没有照搬。DataWork 使用可处理不等样本量的 Tukey-Kramer，并区分探索性事后比较与预先计划对比。

# 跨模型校正与重复运行审计

## 结论

DataWork 中存在三个容易混淆、但作用层级完全不同的概念：

1. **数据校正（Calibration）**：在模型拟合前变换数值列，例如 z-score、稳健 z-score 或基线中心化。它处理量纲、数据源系统偏差和基准对齐，不控制多重检验误报率。
2. **跨模型多重校正**：同一次执行展开多个模型任务时，对主要/总体检验形成的 p 值家族应用 Holm、Bonferroni、FDR-BH 或不校正。它处理“同时检验越多，至少出现一次偶然显著的概率越高”的问题。
3. **重复运行**：用户再次启动同一计划或在修改参数后重新运行。每次运行都有独立 run ID、结果和可复现元数据；历史运行不会被自动拼接成一个校正家族。

## 为什么需要跨模型校正

若每个原假设都按 `alpha=0.05` 判断，单个正确原假设误报的概率是 5%。当一次工作流同时检验多个模型时，至少一次偶然显著的概率会随检验数量增加。因素组合、多因变量逐项分析和按数据分层拆分都会产生这种问题。

- **Holm**：默认选择，控制家族错误率，通常比普通 Bonferroni 更有检验效能。
- **Bonferroni**：控制家族错误率，简单但较保守。
- **FDR-BH**：控制发现中的预期错误比例，适合较多探索性假设，但语义不同于家族错误率。
- **不校正**：仅适合假设彼此独立且已预先明确、或用户有外部校正方案的场景。选择后内核只按原始 p 与 alpha 判断，不生成 `p_adjusted_across_tasks` 或 `significant_adjusted`；界面、报告和导出也不显示“校正后”字段。

## 内核边界

- 校正范围是**一次批量执行**中的主要检验或总体检验。
- 模型系数、EMM、事后比较和字母分组不混入跨模型校正层；它们使用各自定义的对比校正。
- MANOVA 的 Pillai、Wilks、Hotelling–Lawley 与 Roy 按统计量名称分别成族，避免把替代判据混为一个家族。
- 启用校正时同时保留原始 p、跨模型校正 p、判断方法和检验家族；在“不校正”模式下只保留原始 p 与原始显著性，校正字段为空。
- 单模型执行不应用跨模型校正；所选方法会保存到计划中，供以后批量展开时使用。

## 组合模型与重复运行的区别

组合模型在点击确认前已经知道本次会生成哪些任务，因此系统能在同一个结果集中统一校正。重复运行则可能发生在不同时间、使用不同参数，统计内核无法推断用户是否把它们视为同一个研究假设族，也不应静默修改历史结论。

因此界面采用两种提醒：

- 同一次执行包含多个模型时，预检弹窗显示任务数量、跨模型校正方法，并要求确认。
- 已存在历史运行时，预检弹窗提示将创建新的独立运行，说明历史结果不会自动跨运行校正，并提醒避免反复试探后只报告显著结果。

## 兼容性

规范计划字段为 `cross_model_p_adjust`。旧计划中的 `combination_p_adjust` 仍会读取，并在规范化时与新字段同步，已有 API、项目和导出文件无需迁移即可继续运行。

# DataWork 0.4.5 阶数控制、事后检验多选与显著性字母分组审查

> 历史说明：0.4.9 已移除新建分析中的统一阶数控制入口。旧 `factorial_anova` 计划会自动迁移到单因素、双因素或三因素 ANOVA；事后检验多选与字母分组继续保留。

## 1. 审查目标

本版本针对四项需求完成实现和验证：

1. 将完整成对比较结果转换为紧凑显著性字母分组（Compact Letter Display, CLD）；
2. 为 MANOVA 增加 1/2/3 阶模型控制，并在候选因素超阶时显式展开组合实验；
3. 为普通析因 ANOVA 增加相同的阶数控制；
4. 将 Tukey、Duncan 等事后检验改为带说明的可单选/多选参数。

## 2. 因素阶数与候选因素

### 2.1 普通方差分析

统一入口为“单/双/三因素及多候选因素组合方差分析（阶数控制）”。

- 阶数 1：每个模型使用 1 个分类因素；
- 阶数 2：每个模型使用 2 个分类因素，并包含两个主效应和二因素交互；
- 阶数 3：每个模型使用 3 个分类因素，并包含主效应、两两交互和三因素交互。

候选因素数 `n` 大于阶数 `k` 时，只有用户确认后才生成 `C(n,k)` 个独立模型。组合模型不是一个包含全部候选因素的高阶模型。

### 2.2 MANOVA

MANOVA 仍要求至少两个联合因变量。因素阶数只控制每个联合响应模型使用几个对象间因素：

- 3 个候选因素、阶数 1：执行 3 个单因素 MANOVA；
- 3 个候选因素、阶数 2：执行 3 个双因素 MANOVA；
- 3 个候选因素、阶数 3：执行 1 个三因素 MANOVA。

组合任务继续应用跨模型 Holm、Bonferroni、FDR-BH 或不校正，并在预检中明确任务数量。

## 3. 事后检验多选

当前参数使用 `posthoc_methods` 列表。界面支持单选或多选，并提供默认值。

- Tukey–Kramer：适合全部两两比较，控制家族第一类错误率，作为常规默认；
- Duncan：较宽松，容易检出差异，也更容易增加第一类错误，保留用于农业领域兼容或探索性分析；
- Games–Howell：用于方差不齐的独立组比较；
- Dunnett：只比较处理组与指定对照；
- Holm/Bonferroni/Šidák/FDR-BH：根据原始成对检验 p 值进行不同方式的多重校正；
- Scheffé：保守，可支持更广泛的线性对比；
- Fisher protected LSD：总体检验显著后执行，但成对层面未控制家族错误率。

选择多个方法时，每种方法独立计算、独立标记校正方法、独立生成字母分组，不会将不同方法的结论混在同一字母体系中。

## 4. CLD 生成规则

CLD 使用完整的成对显著性矩阵生成：

- 显著差异的两个水平不得共享任何字母；
- 差异不显著的两个水平至少共享一个字母；
- 按均值或模型 EMM 从高到低排列，最高均值优先获得字母 `a`；
- 链式重叠可生成 `a / ab / b`；
- 超过 26 个字母列时支持 `aa`、`ab` 等扩展标签。

Dunnett 不覆盖处理组之间的全部组对，不能形成完整比较矩阵，因此程序保留对照比较表但不生成完整 CLD，并给出原因提示。

## 5. 输出位置

字母分组已写入统一结果字段 `significance_letters`，并显示或导出到：

- 即时分析网页结果；
- 项目工作区运行结果；
- Markdown 统计报告；
- Excel 工作表“显著性字母分组”；
- 组合分析汇总中的 `letter_group` 记录。

## 6. 兼容性

- 旧计划中的 `posthoc_method` 自动转换为 `posthoc_methods`；
- 旧 MANOVA 计划若没有 `factor_model_order`，按原固定因素数量恢复 1–3 阶；

## 5. 本轮发现并修复的问题

### 5.1 t 检验结果语义

旧实现把 `t²=F` 放入总体 F 检验结构，数值关系成立，但会丢失 t 值方向并使普通用户误以为执行了 ANOVA。

现已改为：

- 主要检验直接报告有方向的 t 值；
- 同时报告自由度、p 值和均值差置信区间；
- 效应量保留 Cohen's d、Hedges' g，并补充 η²；
- 运行历史比较同时读取 `primary_tests`，t 检验不再出现对比结果为空。

### 5.2 Fleiss κ 伪 p 值

旧实现只有 κ 点估计，却用 `p=1` 占位，容易被解释为“已经检验且不显著”。

现已改为：

- `p_value=None`；
- `is_significant=None`；
- 网页和报告显示“未提供推断检验”，不再显示“不显著”。

### 5.3 推断结果提前舍入

部分 ANOVA 和事后检验在计算层把 p 值提前保留到 6 位，极小 p 值可能变为 `0.000000`。

现已改为核心保留完整浮点精度，仅在界面和报告显示层格式化。

### 5.4 混合设计成对比较置信区间

经典混合 ANOVA 的部分成对比较曾输出占位区间 `[0, 0]`。

现已根据所选 Holm、Bonferroni、Šidák 或未校正规则计算真实临界值和置信区间；结果模型也允许在方法确实不提供区间时使用空值，而不伪造数字。

## 6. MANOVA 核心核对

单因素、双因素和三因素 MANOVA 分别使用固定 1、2、3 个对象间因素，并以至少两个联合因变量建模。

黄金数据集逐项核对：

- Pillai 轨迹；
- Wilks' Lambda；
- Hotelling–Lawley 轨迹；
- Roy 最大根；
- 近似 F；
- 分子/分母自由度；

普通用户默认只显示较稳健的 Pillai 轨迹；全部四种统计量仍保留在专业模式。

# DataWork 0.4.3 智能设计审查、MANOVA 与混合设计专项验证

## 分析目的

- 审查内容包括完整样本数、设计单元数、最小/最大单元重复、平衡比、残差自由度、重复水平完整性和预计引擎；
- MANOVA 额外检查因变量数量、相关冗余、完整单元和残差信息；
- 混合设计额外检查同一对象的对象间因素是否固定、重复观测是否完整以及是否需要 MixedLM；
- AI 分析计划新增设计审查摘要、设计检查和建议动作；
- 外部模型不可用时，确定性分析目的、预期效果和设计审查仍正常工作。

### 可信边界

AI 不计算 F、p、效应量或模型系数。统计数值、设计计数和引擎选择均由本地确定性代码完成，AI 只负责基于当前上下文解释。

## 二、单/双/三因素 MANOVA

### 模型范围

| 固定因素数 | 模型 | 检验效应 |
|---:|---|---|
| 1 | `A` | A |
| 2 | `A * B` | A、B、A×B |
| 3 | `A * B * C` | A、B、C、A×B、A×C、B×C、A×B×C |

因素统一按分类变量处理，并使用 Sum 对比。公式内部采用隔离列名，已修复真实数据列名为 `C` 时与 Patsy 分类函数冲突的问题。

### 多元统计量

支持全部或单独输出：

- Pillai 轨迹；
- Wilks' Lambda；
- Hotelling–Lawley 轨迹；
- Roy 最大根。

“输出统计量”与“主要多元判据”相互独立。主要判据可用于触发后续分析，但不会被强制添加到用户选择的显示结果中。

### 假设与结构诊断

- Box's M 检查完整因素组合间协方差矩阵相近性；
- Mardia 残差偏度与峰度作为多元正态近似诊断；
- Bartlett 相关矩阵球形检验用于判断因变量是否具有可分析的相关结构；
- 输出因变量相关矩阵和条件数，并提示近完全线性冗余；
- 预检检查空单元、单例单元、模型秩和残差自由度。

Box's M 和 Mardia 对样本量与分布偏离较敏感，因此软件将其作为诊断证据，而不是机械决定是否允许 MANOVA 的唯一开关。

### 单变量跟进

支持：

- 不跟进；
- 仅对主要多元判据显著的效应跟进；
- 对全部效应跟进；
- Type I、Type II 或 Type III 平方和；
- Holm、Bonferroni、Šidák、FDR-BH 或不校正的跨因变量/效应校正。

跟进结果保留原始 p 值和校正 p 值，避免把多个单变量检验误当作单一假设。

## 三、统一事后比较体系

### 支持的方法

| 方法 | 适用重点 | 风险/边界 |
|---|---|---|
| Tukey–Kramer | 所有组两两比较，允许样本量不同 | 常规首选之一 |
| Games–Howell | 单因素且方差不齐 | 不要求等方差 |
| Holm | 通用逐步校正 | 默认稳健选择 |
| Bonferroni | 通用强控制 | 较保守 |
| Šidák | 通用强控制 | 依赖比较族设定 |
| FDR-BH | 探索性多比较 | 控制 FDR 而非 FWER |
| Scheffé | 任意线性对比 | 非常保守 |
| Duncan MRT | 农业研究传统分组 | 较宽松，第一类错误可能膨胀 |
| Fisher protected LSD | 总体检验显著后比较 | 仍属于未充分校正的宽松方法 |
| Dunnett | 多个处理与一个明确对照 | 必须指定唯一对照水平 |

### 析因模型处理

双因素、三因素 ANOVA 和 MANOVA 的事后比较基于模型估计边际均值，而不是在不平衡设计中直接比较原始边际均值。高阶交互显著时，软件阻止或警示自动主效应比较，并要求优先解释条件简单效应或预先规划对比。

## 四、自适应混合设计

### 引擎选择

| 数据结构 | 自动引擎 |
|---|---|
| 1 个对象间因素，完整且平衡 | 经典混合 ANOVA |
| 1 个对象间因素但组间不平衡 | MixedLM |
| 部分重复时间点缺测 | MixedLM |
| 2 个对象间因素 × 1 个重复因素 | MixedLM |
| 用户强制经典但不满足条件 | 预检阻止 |

### MixedLM 路径

- 受试者随机截距；
- 可选重复因素随机斜率；
- 一至两个对象间因素与重复因素的完整固定效应交互；
- 自动尝试 L-BFGS、Powell 和 CG，或由用户指定；
- 联合固定效应 Wald χ²；
- 固定效应系数、随机截距方差、残差方差、AIC/BIC、对数似然和收敛状态；
- 完整单元、对象内或对象间 EMM；
- 统一事后比较与 Dunnett 对照设置。

Wald χ² 与经典 F 的分布和自由度定义不同，结果结构和界面会明确标识实际检验类型。

## 4. 发现并修复的计算问题

### 4.1 t 检验 η²

旧实现通过 Cohen’s d 的近似关系换算 η²，在样本不等或 Welch 自由度下并不等同于检验统计量定义。现统一为：

```text
η² = t² / (t² + df)
```

无限 t 值返回 η²=1。

### 4.2 配对 Hedges 校正

配对效应量应基于配对差值，校正自由度为有效配对数 `n-1`。旧实现可能沿用两个独立样本的自由度。现已分离独立与配对路径，并报告校正自由度。

### 4.3 零标准误退化情形

当所有组内值完全相同但组均值不同，MSE/SE 可以为 0。旧代码把任何除零情况都映射为统计量 0，导致 p=1。现规则为：

- 差值=0 且 SE=0：统计量 0；
- 差值≠0 且 SE=0：有方向的 ±∞，p=0。

该规则已用于 t、EMM、Tukey/Duncan 型对比和混合模型系数。

### 4.4 Mann–Whitney 秩二列方向

方向统一为：

```text
r_rank-biserial = 2U/(n1*n2) - 1
```

第一组总体秩较大时为正，并验证组样本量为正。

### 4.5 Kruskal–Wallis 跟进

旧界面/文档称为 Dunn，但执行的是逐对 Mann–Whitney。现实现真正 Dunn：

- 对全部组共同排名；
- 使用全局平均秩差；
- 应用并列值修正；
- 计算正态近似 z；
- 对全部组对使用 Holm 校正；
- CLD 根据校正后的完整显著性矩阵生成。

### 4.6 Logistic 拟合指标

旧 `pseudo_r2` 实际为离差解释率，却标为 McFadden R²。现分别报告：

```text
McFadden R² = 1 - LL_model / LL_null
Deviance explained = 1 - deviance / null_deviance
```

避免同名异义。

### 4.7 MANOVA 组合校正族

同一个效应可同时输出 Pillai、Wilks、Hotelling–Lawley 和 Roy，这些是替代性多元判据。跨组合校正现按 `statistic_name` 分族，避免把四种判据混进同一个 p 值家族后过度校正或产生难以解释的标签。

### 4.8 重复测量对比

Holm/FDR 等 p 值校正不能被错误标注为完全相同的同时置信区间。现校正方法、区间方法和说明保持一致；无法直接构造相同意义校正区间时明确标记为未校正区间。

### 4.9 常数与方差退化数据

常数列不再直接调用会产生运行时警告的 Shapiro/Levene 底层函数。系统返回明确的“零方差/不可用于该假设检验”诊断，同时由预检决定是否允许后续方法。

## 5. 独立参考交叉验证

### 5.1 Tukey–Kramer

使用不等样本量数据，将所有组对的均值差、标准误、学生化极差 p 值与 statsmodels `pairwise_tukeyhsd` 比较，结果在数值容差内一致。

### 5.2 双因素 Type III ANOVA

使用 Sum 对比编码建立相同完整析因模型，平方和、自由度、F 和 p 与 statsmodels `anova_lm(..., typ=3)` 一致。

### 5.3 MANOVA

对同一多响应析因模型，与 statsmodels `MANOVA.mv_test()` 比对：

- Pillai trace；
- Wilks’ lambda；
- Hotelling–Lawley trace；
- Roy’s greatest root；
- 近似 F、分子/分母自由度和 p。

逐项一致。

### 5.4 Logistic

从模型对数似然和空模型对数似然独立重算 McFadden R²，与程序输出一致；离差解释率单独验证。

### 5.5 CLD 性质测试

对五个组全部 10 个组对的 1024 种显著/不显著图穷举验证：

- 每个水平至少有一个字母；
- 显著组对不共享任何字母；
- 非显著组对至少共享一个字母。

Dunnett 等不完整比较矩阵继续拒绝生成完整 CLD。
