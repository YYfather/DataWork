# DataWork 0.4.7 MANOVA 交互简化记录

## 目标

降低单、双、三因素 MANOVA 的选择复杂度，并消除已完成选择后仍显示缺少设置的问题。

## 新交互

1. 方法列表直接显示“单因素 MANOVA”“双因素 MANOVA”“三因素 MANOVA”。
2. 方法卡片明确显示固定需要的分类因素数，不再显示最小/最大因素范围。
3. 选择数量不足时，直接提示“还需选择 N 个分类因素”。
4. 达到固定数量后，计划状态立即变为可预检，不要求额外设置模型阶数。
5. 继续选择额外因素时，弹窗说明这些因素将形成候选池，并预览 `C(n,k)` 个同阶模型。
6. 取消组合实验时，额外因素不会加入；确认后才展开批量任务。
7. 旧项目在加载时自动迁移，不要求用户手动重选方法。

## 一致性约束

前端缺失项判断、后端计划验证、预检、执行器和 AI 说明均读取方法的同一个固定因素数约束。
