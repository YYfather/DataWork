# DataWork 0.4.7 发布就绪增量审查

## 审查范围

本次审查在 0.4.6 全链路与计算核心审查基础上，重点验证 MANOVA 固定入口、必要设置判断、组合实验、旧计划迁移以及特殊因素列名下的交互后续分析。计算核心的基础交叉验证仍以 `RELEASE_READINESS_AUDIT_0.4.6.md` 为依据。

## 修复结论

- 新建分析不再使用统一 MANOVA 的最小/最大因素范围和额外阶数参数；
- 方法目录提供单因素、双因素、三因素 MANOVA 三个固定入口；
- 三个入口分别恰好需要 1、2、3 个分类因素；
- 因素已经选择完整时，前端缺失项、预检和计划规范化使用同一规则，不再误报“缺少必要设置”；
- 继续选择因素时才提示组合实验，确认后固定执行当前方法阶数的 `C(n,k)` 个模型；
- 旧统一 `manova` 计划按保存阶数或因素数量迁移到新入口；
- 修复交互效应名称还原的子串冲突，`MF2` 等因素名不再被错误改写。

## 验证结果

- 单元测试：125 项通过；
- 集成、API 与端到端测试：39 项通过；
- 合计：164 项通过；
- 46 个可见可执行方法与 46 个执行器一一对应；
- 三个固定 MANOVA 入口均通过完整角色预检和实际执行；
- 前端 TypeScript 检查与生产构建通过；
- 旧计划迁移、超额因素确认和特殊列名均有专项回归测试。

## 发布判断

0.4.7 已消除 MANOVA 方法范围、阶数参数与界面缺失判断之间的双重控制。新用户只需先选择明确的方法，再按固定数量选择因素；组合实验属于显式的可选扩展，不再影响普通单模型工作流。
