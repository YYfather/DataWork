# DataWork 0.4.6 最终交互优化记录

## 1. 分析目的

在统计计算核心完成发布前审查后，对即时分析和项目工作区进行最后一轮交互优化，降低变量角色、因素阶数、组合任务、多选事后检验和结果失效过程中的误操作风险。

## 2. 预期效果（Expected Outcome）

- 用户始终知道当前位于导入、检查、计划、预检、运行还是结果阶段；
- 重要状态变化不静默发生；
- 超额因素和组合实验在执行前可见、可取消、可追溯；
- 多选参数清楚显示已选项、默认项及恢复入口；
- 交互优化不改变 `AnalysisPlan`、统计参数和计算核心。

## 3. 已完成优化

### 3.1 工作流进度

即时分析和项目工作区顶部新增五阶段进度条。完成、当前和未开始阶段使用不同状态，移动端改为横向滚动，不遮挡主体内容。

### 3.2 结果失效透明化

修改文件、方法、变量角色或参数后，旧结果仍按安全规则立即隐藏，但现在会显示失效原因，而不是无提示消失。重新运行成功后提示自动清除。

### 3.3 角色选择

- 已选按钮显示“已选”；
- 增加 `aria-pressed` 状态；
- 提供“恢复推荐选择”，按当前方法和数据推断重新应用角色；
- 冲突角色仍由原有互斥逻辑自动清理。

### 3.4 因素阶数与组合任务

超出单个模型阶数时的确认弹窗新增：

- 实际跨模型校正方法；
- 前 12 个具体因素组合；
- 超过 12 个时显示总任务数；
- 明确说明这些是多个独立模型，不是一个超阶模型。

### 3.5 多选高级参数

多选事后检验等参数新增：

- 已选择数量；
- 每个选项的选中符号；
- 默认选项标记；
- 一键恢复方法注册表默认值；
- 单选、多选、`auto` 和 `none` 互斥规则保持不变。

### 3.6 键盘与可访问性

- `Esc` 可关闭因素组合确认、预检、AI 设置和助手抽屉；
- 所有按钮继续通过可访问名称审查；
- 动画遵守 `prefers-reduced-motion`；
- 界面版本号读取 `/api/health`，不再硬编码旧版本。

## 4. 验证

- Vue TypeScript 检查和 Vite 生产构建通过；
- Playwright 真实浏览器流程通过：数据读取、工作流状态、预检、结果失效、错误恢复、AI 抽屉、项目保存、运行和报告下载；
- 前端交互契约测试新增对工作流条、失效原因、推荐恢复、参数默认恢复、组合清单、Esc 和动态版本号的检查；
- 后端 `AnalysisPlan`、参数序列化和统计执行器没有因本轮界面优化发生字段变化。

## 5. 边界

交互优化不能替代统计设计判断。组合任务数量、事后方法选择和显著性字母分组仍需根据预先研究假设、实验设计和错误率控制策略解释。

## 6. AI 操作助手悬浮窗

原有 AI 助手使用带遮罩的固定侧边抽屉，打开后会阻断主界面操作。现已改为非阻塞式悬浮窗：

- 标题栏可拖动，用户可以把助手移动到不遮挡数据表、分析参数或结果的位置；
- 右下角提供明确的缩放手柄，可自由调整宽度与高度；
- 提供最小化、展开、关闭和恢复默认位置/尺寸按钮；
- 桌面端使用 `localStorage` 保存窗口位置、尺寸和最小化状态；
- 浏览器窗口尺寸变化后自动约束悬浮窗，避免标题栏或缩放手柄移出可视区；
- 支持 `Alt + 方向键` 微调位置，`Alt + Shift + 方向键` 微调尺寸；
- 移动端禁用拖动和自由缩放，自动切换为留有安全边距的近全屏窗口；
- 打开助手时隐藏右下角启动按钮，关闭后恢复，减少界面重复控件；
- AI 设置对话框仍保持更高层级，不会被悬浮窗遮挡。

该改动仅影响前端窗口管理，不改变 AI 请求内容、隐私范围、统计结果 Guard 或任何统计计算参数。
