# DataWork 0.4.8 参数、结果下载与 AI 悬浮窗审查

## 修复目标

1. 让所有即时单次分析均能下载结果；
2. 降低普通用户面对的参数数量；
3. 简化默认结果表，同时保留完整统计信息；
4. 修复 AI 悬浮窗拖动、缩放和位置约束。

## 即时结果下载

新增 `POST /api/instant/reports`。接口对分析执行结果进行统一模型校验后，使用与项目工作区相同的 `ReportService` 生成：

- `results.xlsx`；
- `statistical_report.md`；
- `canonical_result.json`；
- 可复现计划、环境和溯源文件；
- 完整 ZIP 报告包。

结果页提供“下载结果 Excel”和“下载完整报告 ZIP”。批量分析继续使用合并 XLSX。

## 参数层级

默认进入简洁模式：

- 方法默认值自动应用；
- 页面只显示推荐设置摘要；
- 事后检验等常用选项位于可折叠的“调整常用设置”；
- α、平方和、置换/精确算法、诊断图、EMM 和低频选项仅在专业模式显示；
- 参数仍完整写入分析计划、预检、溯源和报告，计算核心未删除任何能力。

## 结果呈现

新增统一 `AnalysisResultView`：

- 默认显示核心检验、统计量、p 值、效应量和显著性结论；
- ANOVA/MANOVA 显示总体效应与必要的单变量跟进；
- 回归显示主要系数；
- 显著性字母分组保留为核心结果；
- 详细模式显示自由度、置信区间、诊断、简单效应、EMM、完整对比、拟合指标、图形和描述统计；
- 即时分析与项目工作区共用同一组件，避免字段和解释不一致。

## AI 悬浮窗

- 八方向缩放：四边和四角均可拖动；
- 标题栏稳定拖动；
- 左右停靠；
- 最大化和还原；
- 最小化、关闭和恢复默认布局；
- 使用 `visualViewport` 处理浏览器缩放、移动视口和窗口改变；
- 位置与尺寸保存在本地；
- 移动端继续使用安全近全屏布局。
