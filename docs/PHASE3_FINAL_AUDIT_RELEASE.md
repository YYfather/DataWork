# DataWork 0.4.0 最终全面检查

## 审查范围

- 统计方法注册表与执行器一致性；
- AnalysisPlan 角色、参数和列冲突；
- 分类因素组合与批量 p 值校正；
- 重复测量、经典混合设计、随机斜率和 EMM；
- AI 设置与密钥不落盘边界；
- 分析前检查；
- SQLite 工作区与报告；
- Vue/TypeScript 生产构建；
- Windows/Linux/macOS 路径和启动脚本；
- 密钥、动态执行、危险反序列化和 shell 调用扫描。

## 已修复问题

1. 删除旧测试对混合设计“未实现”的错误假设。
2. 清理重复统计计算和重复执行语句。
3. 将运行时 `assert` 改为显式验证错误。
4. 跨任务多重校正仅处理主要/总体检验，不再把模型系数混入同一假设族。
5. 零方差配对差值使用显式退化结果，避免精度丢失警告。
6. REML 下不再把无定义的 AIC/BIC 显示为 0。
7. 报告图自动选择系统 CJK 字体，缺少时安全回退。
8. 前端角色切换时自动移除失效的随机斜率和 EMM 因素。
9. 所有 43 个可执行方法均有已注册执行器。

## 保留边界

- 经典混合设计仅支持一个对象间因素 × 一个对象内因素的完整平衡设计。
- 线性混合模型当前支持一个随机分组因素，不宣称支持完整交叉/多成员随机结构。
- EMM 使用等权分类参考网格和样本均值协变量；复杂自定义权重和任意线性假设矩阵尚未开放。
- Tauri 外壳已提供源码和 sidecar 契约，但当前 Linux 环境没有 Rust 工具链，因此未伪造未编译的三系统安装包。
## 最终验证结果

- Python 全量编译通过；
- 74 项自动化测试全部通过；
- 核心、应用、统计引擎与 Web API 综合覆盖率约 78%；
- 43 种统计方法定义全部可执行，并与 43 个执行器一一对应；
- Vue 3 + TypeScript 生产构建通过，安装包内网页静态资源可正常加载；
- 经典混合设计通过 API 预检与执行，返回对象间效应、对象内效应和交互效应；
- 同一端到端任务生成 6 个 EMM、9 个校正对比和 4 张诊断图；
- 报告包生成 Markdown、canonical JSON、Excel、PNG 图形及可复现元数据；
- Wheel 独立目标目录安装验证通过，未依赖源码工作目录；
- Tauri JSON 配置与外壳源码结构检查通过；当前环境未安装 Rust，因此未宣称完成原生编译；
- 安全扫描未发现运行时 `eval`、`exec`、`pickle.loads`、`shell=True`、`os.system`、硬编码生产密钥或构建机绝对路径。
