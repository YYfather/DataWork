## 2. 统计语义

“因变量排列组合”按 MANOVA 模型语义实现为无序组合。`Y1 + Y2` 与 `Y2 + Y1` 是同一个联合响应模型，只生成一次。

专业模式提供三种互斥的联合响应任务模式：

- `joint_all`：全部已选因变量进入一次联合分析；
- `manual_groups`：沿用 V1.5 的手工互斥分组，每个因变量必须且只能属于一组；
- `combinations`：按组合大小范围自动生成组合，变量可以进入多个组合。

组合大小至少为 2，默认固定为 `2–2`；用户可在 2 至已选因变量数量之间设置最小值和最大值。组合按计划中因变量的稳定顺序生成。

## 3. 数据模型与兼容

`AnalysisPlan` 增加：

- `dependent_task_mode`：`joint_all | manual_groups | combinations`；
- `dependent_combination_min_size`；
- `dependent_combination_max_size`；
- `dependent_combination_labels`。

兼容规则：

- 缺少新字段且存在 `dependent_variable_groups` 的旧计划迁移为 `manual_groups`；
- 缺少新字段且没有手工组的旧计划保持 `joint_all`；
- `manual_groups` 与 `combinations` 不得同时启用；
- 新字段仅允许联合响应方法使用，自动组合仅在专业模式开放；
- 手工组仍保持完整互斥分区，不放宽为重叠组；
- 自定义组合名称只改变显示，不改变成员、顺序、模型公式或复现标识。

## 4. 唯一任务展开与任务上限

预检和执行共同使用 `outcome_tasks()` 与 `factor_tasks()`，不得分别实现组合逻辑。

总任务数：

`因变量任务数 × 因素模型数 × 拆分组数`

- 超过 200 个任务：强警告；
- 超过 1000 个任务：阻止执行；
- 每个子任务单独检查完整案例、因素水平、设计矩阵秩、残差自由度和 MANOVA 响应矩阵稳定性；
- 失败任务保留组合标识和明确原因，不影响其他可执行任务；
- 跨模型校正默认 Holm，并按统计量家族分别执行。

批量任务至少记录：

- `task_id`；
- `dependent_combination`；
- `dependent_columns`；
- `dependent_combination_size`；
- `factor_combination`、`factor_columns`、`combination_order`；
- 拆分标签、样本量、状态和失败原因。

## 5. 八个 ANOVA/MANOVA 核心审计

覆盖：

- 单、双、三、4–8 因素 ANOVA；
- 单、双、三、4–8 因素 MANOVA。

必须核对：

- 因素数与方法阶数严格一致；
- Type I/II/III 平方和和 Type III Sum 对比；
- 完整析因公式、全部主效应和交互；
- 空单元、完全混杂、秩不足和无残差自由度；
- 常数因变量、严重共线、奇异协方差和样本不足；
- Pillai、Wilks、Hotelling–Lawley、Roy 与预先指定主要判据；
- Box's M、Mardia、相关矩阵与条件数；
- 单变量跟进的门控、校正、简单效应、EMM、事后比较和字母分组；
- 4 因素以上显著交互不自动指数级展开简单效应，并明确报告限制；
- 因素组合映射到 1/2/3/4–8 阶执行器时正确过滤参数。

MANOVA 引擎不得用 `None` 隐藏失败原因；必须抛出可定位的数据或模型错误。

## 7. 前端与交互

即时分析和项目工作区专业模式均增加联合响应任务选择：

- 全部联合分析；
- 手工分组；
- 自动因变量组合。

自动组合界面显示：

- 候选因变量数；
- 最小/最大组合大小；
- 因变量组合数；
- 因素模型数；
- 拆分组数；
- 预计总任务数；
- 前若干个组合预览；
- 跨模型校正方式。

启用自动组合需明确确认；简洁模式不显示该功能。切换方法、删除或重命名因变量时必须同步规范组合配置和自定义名称。
