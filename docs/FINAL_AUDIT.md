# DataWork 最终审查索引

当前发布候选版本为 **0.4.9**。现行工程规范、测试结论和发布资产已分别归并至：

- `PROJECT_STANDARD.md`：统一工程规范；
- `TEST_REPORTS.md`：当前门禁及全部历史测试索引；
- `DEVELOPMENT_LOG.md`：关键决策与技术路径；
- `../CHANGELOG.md`：统一全局版本更新记录；
- `RELEASE_MANIFEST.md`：目录、包含/排除范围与归档步骤；
- `USER_MANUAL.md`、`STATISTICAL_METHODS.md`：用户和统计权威手册。

历史 `*_AUDIT*.md` 文件作为不可变审计证据保留，不再承担现行规范定义。正式原生安装包仍需按 `PACKAGING.md` 和 `RELEASE_CHECKLIST.md` 在目标系统分别构建、签名和执行首次启动冒烟测试。
