# DataWork 第三阶段说明（0.4.0）

## 分析目的

第三阶段针对重复测量、层级数据和复杂模型结果阅读，补齐经典混合设计、球形性校正、随机斜率、模型边际均值、对比和诊断图，并建立 Tauri 2 桌面 sidecar 契约。

## 预期效果（Expected Outcome）

用户可以在统一分析计划中配置对象 ID、对象内因素、对象间因素、随机分组和随机斜率。运行后除主要检验外，还可获得球形性结果、GG/HF 校正、EMM、校正后的对比、模型诊断图和可复现报告包。

## 新增能力

### 重复测量与经典混合设计

- 单因素重复测量 ANOVA：完整平衡长表；Mauchly、Greenhouse–Geisser、Huynh–Feldt；重复水平成对比较。
- 混合设计 ANOVA：一个对象间因素 × 一个对象内因素；完整且组间对象数相同；对象间、对象内和交互效应使用各自误差项。
- 不完整或不平衡重复设计会被预检阻止，并建议改用线性混合模型。

### 线性混合模型

- 一个随机分组因素；
- 随机截距；
- 最多两个用户选择的随机斜率；
- REML/ML、优化器和迭代上限；
- 收敛、奇异协方差和组内变化预检；
- REML 下不伪造 AIC/BIC；
- 随机方差、协方差、残差方差和 ICC。

### EMM 与对比

支持 ANOVA、ANCOVA、线性回归和线性混合模型的模型设计矩阵后处理：

- 分类因素的等权参考网格；
- 连续协变量固定在样本均值；
- EMM、标准误和置信区间；
- 两两对比；
- Holm、Bonferroni、FDR-BH 或不校正。

### 诊断图

canonical JSON、网页和报告包共用结构化图形数据：

- 残差－拟合值；
- 正态 Q–Q；
- 尺度－位置；
- Cook 距离与杠杆值；
- 因素交互作用图；
- 重复水平均值图。

报告生成器会在目标系统可用时选择 CJK 字体，不附带或分发字体文件。

### 桌面运行基础

`desktop/` 提供 Tauri 2 外壳源码：

1. 启动 PyInstaller 生成的 `datawork-sidecar`；
2. 轮询 `/api/health`；
3. 加载同一套本地网页；
4. 窗口退出时终止 sidecar。

正式安装包必须在 Windows、Linux、macOS 各自原生构建和签名。
