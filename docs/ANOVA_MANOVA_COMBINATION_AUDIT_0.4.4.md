# DataWork 0.4.4 ANOVA、MANOVA 与因素组合专项验证

## 分析目的

核对单因素、双因素、三因素 ANOVA 和 MANOVA 的变量定义、模型公式、交互后续分析、EMM 参数传递及超额因素组合行为，确保界面、分析计划、预检、统计执行器和报告一致。

## 预期效果（Expected Outcome）

- MANOVA 的“多元”始终表示至少两个联合因变量；
- 普通单次模型严格使用方法定义的因素数量；
- 超额因素默认不执行，必须由用户确认后才展开组合；
- 显著交互优先进入校正后的条件简单效应；
- 组合任务数、组合内容和跨任务校正可在执行前审查。

## 修复内容

### 联合因变量

MANOVA 注册表维持 `dependent_mode=joint`、最少两个因变量。即时分析和项目工作区切换到 MANOVA 后会从候选数值列中自动补足至少两个，并将角色显示为“联合因变量”。执行公式保持：

```text
Y1 + Y2 + ... ~ A * B * C
```

多个因变量不会被拆成多个独立 ANOVA。

### 因素组合确认

组合模式默认关闭。达到方法正常因素上限后继续点击因素，会弹出明确确认窗口；取消时不加入，确认后才进入组合模式。

| 方法 | 单次模型因素数 | 选择 n 个候选因素后的默认任务 |
|---|---:|---:|
| 单因素 ANOVA / Welch / Kruskal 等 | 1 | `C(n,1)` |
| 双因素 ANOVA | 2 | `C(n,2)` |
| 三因素 ANOVA | 3 | `C(n,3)` |
| MANOVA | 1–3 | 超过 3 个时默认 `C(n,3)` |

每个组合是独立模型，不是包含全部候选因素的超阶模型。预检显示模型数、组合阶数、每个任务的可执行性及跨任务 p 值校正。

### 交互后续分析

双因素、三因素 ANOVA 和 MANOVA 的单变量跟进统一执行以下规则：

1. 识别显著的最高阶交互；
2. 停止涉及因素的边际主效应自动比较；
3. 在条件水平组合内拟合简单效应模型；
4. 对简单效应 p 值统一应用 Holm、Bonferroni、Šidák、FDR-BH 或不校正；
5. 仅对校正后显著的简单效应执行条件内 EMM 成对比较。

### MANOVA 诊断

- Bartlett 探索性检验改为完整模型残差相关矩阵；
- 因变量条件数改为标准化矩阵计算，避免单位尺度误报；
- Box's M 使用独立阈值，默认 0.001；
- Mardia 继续使用模型残差；
- 用户指定 EMM、EMM 因素和对比校正实际传入每个单变量跟进模型。

### Dunnett

支持统一对照值：

```text
CK
```

也支持按因素分别指定：

```text
处理=CK;品种=对照品种
```

模型 EMM 场景下明确标记为 Dunnett 型、Bonferroni 保守近似；单因素原始组数据仍可使用 SciPy 单步 Dunnett。

## 统计边界

- 普通 MANOVA 仍是对象间固定效应多响应模型，不是多响应混合效应模型；
- 组合分析增加模型数量，即使有跨任务校正，也不应替代预先规划的主要假设；
- 显著简单效应应结合效应量、置信区间和实验设计解释；
- Duncan 和 Fisher LSD 保留作领域兼容，但默认不启用，并持续显示第一类错误膨胀风险。
