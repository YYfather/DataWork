# DataWork 0.4.2 MANOVA 完善与验证记录

## 分析目的

检查 DataWork 是否真正支持“两个对象间分类因素 × 多个连续因变量”的双因素 MANOVA，确认 Wilks、Pillai、Hotelling–Lawley 和 Roy 四种多元检验统计量能否由用户选择，并修复从界面、执行器、统计引擎到报告导出的完整链路。

## 预期效果（Expected Outcome）

- 选择 1 个分类因素时执行单因素 MANOVA；
- 选择 2 个分类因素时执行完整析因 MANOVA，输出两个主效应和交互作用；
- 用户可选择全部四种统计量或单独选择其中一种；
- 结果同时显示统计量值、近似 F、自由度和 p 值；
- 数值编码的处理水平仍按分类因素处理；
- 精确为零的效应不会导致整个 MANOVA 崩溃；
- 网页、工作区、API、Markdown 和 Excel 报告结果一致；
- 明确区分对象间双因素 MANOVA 与重复测量混合 MANOVA。

## 原版本检查结果

0.4.1 的方法注册表已经允许 1–2 个固定因素，因此设计意图中包含双因素 MANOVA，但存在以下问题：

1. 统计引擎读取了错误的 `F value` 字段，而 statsmodels 实际返回 `F Value`，导致总体检验行无法写入结果；
2. 引擎使用了不存在的 `Hotelling's T2` 名称，而 statsmodels 返回 `Hotelling-Lawley trace`；
3. 界面没有多元检验统计量选择参数；
4. 数值编码因素未使用 `C(...)`，存在被误当作连续变量的风险；
5. 截距多元检验会进入底层计算，且精确零效应可能触发 statsmodels 的空特征根异常；
6. MANOVA 结果沿用普通 ANOVA 表，实际多元统计量值没有展示，并错误显示不可用的偏 η²=0。

## 本次实现

### 统计模型

- 模型公式：`DV1 + DV2 + ... ~ C(A)` 或 `DV1 + DV2 + ... ~ C(A) * C(B)`；
- 双因素模式检验：A、B、A×B；
- 默认不显示截距检验；
- 对每个模型项独立计算多元统计量，精确零效应返回统计量 0、F=0、p=1；
- 非零数据上的结果与 statsmodels 原生 `mv_test` 数值完全一致。

### 可选统计量

| 参数值 | 界面名称 | 用途提示 |
|---|---|---|
| `all` | 全部四种 | 完整输出，正式结论仍应预先指定主要判据 |
| `pillai` | Pillai 轨迹 | 假设轻度偏离时通常相对稳健 |
| `wilks` | Wilks' Lambda | 经典、最常见 |
| `hotelling_lawley` | Hotelling–Lawley 轨迹 | 综合多个特征根 |
| `roy` | Roy 最大根 | 仅依赖最大特征根，对假设偏离更敏感 |

### 结果输出

MANOVA 专用结果表包含：

- 效应；
- 多元检验统计量名称；
- 多元统计量值；
- 分子和分母自由度；
- 近似 F；
- p 值；
- 显著性结论。

普通 ANOVA 的偏 η²表保持不变；MANOVA 不再显示误导性的偏 η²=0。

## 方法边界

当前实现是 **对象间单/双因素 MANOVA**。它不包含对象 ID、对象内重复因素或随机效应，因此不是严格意义上的重复测量混合 MANOVA。

- 多个因变量 + 1–2 个独立分组因素：使用 MANOVA；
- 一个因变量 + 对象间因素 + 对象内时间/条件：使用混合设计 ANOVA；
- 非平衡重复测量、缺失随访、区组/地点/对象相关性：优先使用线性混合模型；
- 多个因变量 + 重复测量：当前版本未将其伪装为普通 MANOVA，需要后续专门实现重复测量多元模型。

- 自动化测试：121/121 通过；
- 高级参数变体：105 组通过；
- 数据异常与退化变体：350 组完成，所有可执行配置成功，非法配置被预检拦截；
- 生产前端构建：Vue TypeScript 检查和 Vite 构建通过；
- 浏览器交互审查：即时分析、错误处理、AI 抽屉、工作区和报告流程通过；

- 精确零交互测试：四种统计量均返回 F=0、p=1，未发生崩溃。
