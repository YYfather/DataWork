# DataWork 0.4.9 发布就绪审查

## 发布主题

本版本聚焦两个发布前基础能力：

1. 用冻结黄金数据集全面核对计算核心；
2. 降低普通用户参数负担，同时完整保留专业设置。

## 计算核心结论

- 50 个黄金案例、418 个参考断言全部通过；
- 45 个当前可执行统计方法均有默认路径黄金案例，另保留旧 `factorial_anova` 计划迁移案例；
- 关键结果使用 SciPy、statsmodels 或独立公式交叉核对；
- 修复 t 检验结果语义、Fleiss κ 伪 p 值、核心提前舍入和混合设计占位置信区间；
- 工作区跨运行比较已兼容主要检验表；
- MANOVA 默认改为 Pillai，但专业模式仍可输出全部四种多元判据。

## 工作流与边界验证

- 自动化测试：191 项通过；
- 高级参数变体：313 组通过；
- 数据结构变体：378 组完成预检；
- 185 个合法配置全部运行成功且没有非有限统计结果；
- 非法、退化和不可估计配置均被结构化阻止；
- 前端 TypeScript 与生产构建通过；
- 真实浏览器即时分析、预检、结果下载、AI 窗口、项目保存和报告流程通过。

## 普通用户界面结论

- 默认简洁模式；
- 每个方法只显示最多 1–2 个常用参数；
- 常用参数有一句话解释、推荐值和选项级说明；
- 低频与专业参数默认不显示；
- 切换专业模式后全部能力仍可修改；
- 参数始终完整写入计划、计算、溯源和报告。

## AI 悬浮窗结论

修复了八方向缩放命中区域被后置 CSS 重置覆盖的问题。当前真实浏览器已验证：

- 标题栏拖动；
- 四边与四角缩放；
- 最小化/展开；
- 关闭；
- 主界面非阻塞操作。

## 发布边界

本审查证明源码、Web/API 工作流和统计计算核心满足当前发布候选要求，但不等同于 Windows、macOS、Linux 三个平台的签名原生安装包都已完成。

正式独立程序仍需在每个目标操作系统原生执行：

- sidecar 与 Tauri 构建；
- 安装、升级、卸载；
- 首次启动；
- CSV/XLSX 读取；
- 图形和报告生成；
- 用户目录权限；
- 签名及安全软件兼容性。
