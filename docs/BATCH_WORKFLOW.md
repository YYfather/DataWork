# 通用批量与分类因素组合分析工作流

## 分析目的

将“多个因变量、多个数据子集、多个候选分类因素组合”统一为一个可复现的批量计划。用户只需选择候选变量和组合阶数，程序自动展开统计任务、逐项预检、执行并汇总，避免逐个模型重复设置。

## 预期效果（Expected Outcome）

程序会生成完整任务清单。网页先显示结论优先的结果总览，并可切换查看各批次；Excel 使用多个子表保存“结果总览”、逐批结果、“失败与警告”和后置的“分析设置”，避免参数摘要挤占主要结论。

## 核心原则

批量引擎不会：

- 搜索任何预设中文或英文列名；
- 假设固定处理—对照关系；
- 假设时间、品种、地点或区组等业务语义；
- 自动派生领域指标；
- 固定生成某几张业务表格；
- 把所有候选分类因素强行塞进同一个模型。

所有变量角色、组合阶数和高级参数都来自用户当前选择。

## 批量维度

### 多因变量

对于一次接受一个因变量的方法，用户可以选择多个因变量。程序为每个因变量建立独立子计划。

### 拆分列

用户可以选择任意拆分列，但系统默认不拆分，也不会根据类别列自动启用拆分。简洁模式保持原有方式：选列后按实际水平组合拆分数据。专业模式在此基础上允许将多个类别水平合并为命名组，或按自定义数值区间分组；没有自定义规则的已选列仍按原值拆分。除下述受控的固定分类因素例外外，拆分列不能同时承担因变量、协变量、随机因素或对象 ID 等冲突角色。

专业模式允许拆分列同时作为固定分类因素，但必须使用自定义分组，且至少建立两个组。类别分组中的每个组至少包含两个原始因素水平；数值区间则按实际落入区间的不同因素水平审核。程序会在完整案例处理后对每个最终批量任务复核，任一任务不足两个有效水平即阻止整次分析。仅作为拆分列时仍允许单组、单值筛选。未分配到自定义组的水平及其数据行不参与计算，并在预检中记录排除数量。

### 自定义计算列

专业模式可从原始数值列逐行计算自定义列。每个计划最多 10 个自定义列，每列最多引用 10 个互不重复的原始数值列；公式使用方括号引用列名，并仅支持数值常量、括号及 `+ - * / ** %`。结果在进入 Calibration 和统计分析前实际四舍五入到 8 位小数。自定义列不能覆盖原始列、不能引用其他自定义列，并且只能作为因变量（可再 Calibration），不能承担因素、协变量、随机项、对象/重复因素、拆分或 EMM 角色。

自定义列不建立自己的拆分规则，而是继承全部来源原始列的拆分，并受其余全局拆分列约束。例如 `C=f(A,B)` 且分析还按 `Z` 拆分时，任务按 `A × B × Z` 组合；未分配水平不计算，空组合在预检列出后跳过。计算顺序固定为“逐行计算 C → 四舍五入 8 位 → Calibration（若启用）→ 按全局拆分执行”。公式、来源列、精度和无效结果计数写入可复现清理日志，原始数据集保持不变。

### 分类因素组合

启用“分类因素组合实验”后，所选分类因素作为候选池。用户指定最小和最大组合阶数，程序使用无重复组合展开模型。

例外：四至八因素 ANOVA/MANOVA 的即时分析不开放因素组合。这些方法按阶数拟合一个完整高阶模型，若需要分层，应使用专业拆分，避免再叠加组合数量造成指数级负担。

例如，5 个候选分类因素、只执行双因素组合时：

```text
组合数 = C(5, 2) = 10
```

程序会生成 10 个不同的双因素模型，不会重复生成 `A × B` 和 `B × A`，也不会把 5 个因素同时加入同一模型。

### 完整任务数量

```text
任务数 = 因变量数 × 分类因素组合数 × 拆分水平组合数
```

未启用分类因素组合时，当前固定因素列表仅构成一个模型组合。

展开任务超过 200 个时预检给出性能警告；超过 1000 个时阻止执行，要求减少因变量、因素组合或拆分组。

## 多重检验控制

因素组合会产生多个模型和多个 p 值。默认使用 Holm 方法对跨任务 p 值进行校正，也可在高级设置中选择：

- 不校正；
- Bonferroni；
- Holm（默认）；
- Benjamini–Hochberg FDR。

启用 Holm、Bonferroni 或 FDR-BH 时，输出同时保留原始 p 值、校正前显著性、跨任务校正 p 值和校正后显著性。选择“不校正”时只输出原始 p 值与原始显著性，不生成数值相同的伪“校正 p”或“校正后”结论。

## 高级参数

每种统计方法的高级参数默认折叠并使用稳健默认值。需要时可展开调整，例如：

- 卡方检验：连续性校正、功效散度族、渐近/置换/Monte Carlo p 值、重抽样次数、随机种子；
- Fisher/Barnard/Boschloo：备择方向和精确计算选项；
- McNemar：精确、渐近或自动模式；
- 比例检验：成功水平、零假设比例、备择方向、两两比较和校正方法；
- 一致性检验：权重类型；
- 趋势检验：有序水平顺序、分数和备择方向；
- Logistic/多项/有序回归：成功水平、参考水平、水平顺序、链接函数和最大迭代次数。

参数会写入分析计划、运行记录、结果表和可复现性元数据。

## 分析前检查

执行前会检查：

- 方法是否可运行并支持当前变量结构；
- 因变量、分类因素、协变量、随机因素、对象 ID 和重复因素是否达到方法要求；
- 变量角色是否冲突；
- 分类因素组合阶数是否在方法允许范围内；
- 组合任务数是否超过安全上限；
- 高级参数类型、范围和选项是否合法；
- 每个拆分子集和每个因素组合的有效样本量；
- 二元、多类别、有序、配对、分层或重复测量结构是否成立；
- 模型是否存在常数列、空单元、完全分离、奇异矩阵或不足水平等风险。

错误会阻止执行；警告会在确认弹窗中显示。批量运行时，单个任务失败不会丢失其他任务，失败原因会写入汇总表。

## 输出结构

批次分析输出一个多工作表 Excel，阅读顺序如下：

```text
结果总览
批次_001
批次_002
...
失败与警告
分析设置
```

“结果总览”只保留快速判断所需的信息：

- `task_id`；
- `dependent_variable`；
- `factor_combination`；
- `combination_order`；
- 用户选择的拆分列及水平；
- 当前任务样本量；
- 主要统计项与统计量；
- 原始 p 值；
- 校正前显著/不显著结论；
- 启用跨任务校正时才显示 `p_adjusted_across_tasks` 和校正后的显著/不显著结论。

每个“批次_NNN”子表保存对应任务的完整统计结果，包括效应量、诊断、事后比较和描述统计。“失败与警告”集中列出异常，“分析设置”最后记录方法和参数。列结构由实际统计方法和用户配置决定，不依赖固定业务字段。

## 网页使用

1. 上传文件并完成数据检查。
2. 选择统计方法。
3. 选择一个或多个因变量。
4. 多选候选分类因素。
5. 需要组合实验时，开启“分类因素组合实验”。
6. 设置最小/最大组合阶数和跨任务 p 值校正。
7. 需要时展开“高级参数”修改默认值。
8. 需要按子集重复时选择拆分列。
9. 点击“检查并执行分析”。
10. 在预检弹窗中核对任务数、变量结构和问题任务。
11. 确认后运行；网页可在“结果总览 / 逐批查看”之间切换，也可下载多工作表 XLSX。

## CLI 使用

```bash
datawork batch "data.csv" \
  --dv "response" \
  --factor "factor_a" \
  --factor "factor_b" \
  --factor "factor_c" \
  --factor-combinations \
  --min-factor-order 2 \
  --max-factor-order 2 \
  --p-adjust holm \
  --split "site" \
  --method twoway_anova \
  -P continuity_correction=off \
  -o "combination_results.xlsx"
```

CLI 参数必须明确填写，不自动猜测字段。
