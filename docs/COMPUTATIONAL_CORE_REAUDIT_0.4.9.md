# DataWork 0.4.9 计算核心全面复核

复核日期：2026-07-19

## 1. 结论

DataWork 0.4.9 注册的 46 个可运行统计方法均有冻结数据集和独立参考结果覆盖。本轮重新执行 50 个黄金案例、418 个数值断言，全部通过；313 个高级参数变体全部通过；378 个缺失、极小样本、重复行、常数列、类型错误和批量小子集变体均得到有限结果或被结构化阻止。

本轮未发现典型、可估计数据上的计算偏差。发现并修复了一个退化输入缺陷：Stuart-Maxwell/Bhapkar 边际同质性检验在协方差矩阵奇异时可能返回 NaN。修复后预检会阻止该配置，执行器也不会输出非有限统计量；批量分析还会对每个拆分子集重新执行完整校验。

`golden_datasets/data/` 中的 28 个确定性 CSV 覆盖单样本、独立/配对样本、均衡与不平衡析因设计、协变量、重复测量、混合模型、多响应、二元/多分类、分层表和多评分者数据。每个文件在 `golden_datasets/manifest.json` 中记录 SHA-256，数据发生变化会先于数值比较失败。

期望值不由 DataWork 执行器反向生成，参考来源为：

- SciPy 的 t、秩、相关、精确检验和二项检验；

该方案能够发现数据整理、公式构造、参数传递、结果抽取、效应名称、校正和报告语义错误，但不等于重新证明 SciPy 或 statsmodels 底层算法。

## 5. ANOVA 与 MANOVA 解释核对

“连续因变量”不是一种特殊于 MANOVA 的新因变量，而是可以在数值尺度上进行均值、方差和线性组合运算的响应变量，例如身高、产量、评分和浓度。“因变量”是更宽泛的角色名称：它可以是连续、二元、名义多分类或有序分类；类型不同决定应使用 ANOVA/线性模型、Logistic 模型还是列联表方法。

- 单/双/三因素 ANOVA：一个连续因变量，分别由一个、两个或三个分类因素解释；最高阶交互优先解读。
- 单/双/三因素 MANOVA：至少两个连续因变量作为联合响应，一次检验因素对其线性组合的整体影响；先报告多变量判据，再做经多重校正的单变量跟进。
- 总分若由其他因变量精确相加得到，与组成分数同时进入 MANOVA 会产生线性依赖，应删除冗余响应或只把总分作为描述性派生指标。
- DataWork 普通模式默认 Pillai 轨迹，专业模式保留 Wilks、Hotelling-Lawley 和 Roy；这是稳健性选择，不改变底层四种判据的计算。

## 6. 规范报告规则

参考 `参考基准/来自分享的对话.md`，附加报告采用“研究目的与设计 -> 假设和诊断 -> 总体检验 -> 后续分析 -> 效应量与不确定性 -> 结论与限制”的顺序，并执行以下约束：

1. 双/三因素模型先报告最高阶交互；显著时优先简单效应或简单-简单效应，不脱离交互概括被修饰的主效应。
2. MANOVA 先报告多变量判据，再报告校正后的单变量跟进和条件比较。
3. 优先使用校正后 p 值，同时报告校正方法、效应量和已有置信区间。
4. `p >= alpha` 只表述为“证据不足/未达到显著”，不写成“完全相同”或“因素相互独立”。
5. 不把观察性关联写成因果，不从未显著结果推导等效性。

参考对话中的示例数字不会进入提示词或结果；其中“Tukey 仅适用于等样本量”“总体检验不显著时任何预先计划比较都无意义”“交互不显著即因素相互独立”等过强说法没有照搬。DataWork 使用可处理不等样本量的 Tukey-Kramer，并区分探索性事后比较与预先计划对比。

## 7. 附加 AI 报告

新增 `/api/ai/report/result` 和独立网页面板。单次、多次、因素组合及数据拆分结果完成后，界面先以 `use_ai=false` 生成本地固定格式的规范报告；这个阶段不读取 AI 配置，也不创建外部模型请求。用户主动生成 AI 优化报告后，面板增加第二页，可在“内置规范报告”和“AI 优化报告”之间翻页；统计表始终来自计算内核，不交给模型改写。

批量/组合报告会显示任务总数、成功与失败明细、跨模型校正方法、校正后结论和最多前 500 行总览。完整数据通过四个并列入口导出：合并多工作表 XLSX、包含全部附件的 ZIP、规范 Markdown 和 canonical JSON。AI 输出仍经过结构化 Schema 和数值守卫；任何不能追溯到 canonical result JSON 的统计数字都会触发内置保守报告回退，且不会覆盖第一页面或原始导出。

## 8. 剩余边界

- 结果正确性仍依赖固定版本的 NumPy、SciPy、pandas 和 statsmodels；依赖升级后必须重跑黄金套件。
- 极端稀疏、完全分离、秩亏或高维小样本设计可能在统计上不可估计，正确行为是阻止或报告限制，而不是强行产生数值。
- 自动化基准不能替代具体研究中的抽样设计、独立性、缺失机制、量表有效性、功效和因果识别审查。
- 当前唯一测试提示是 FastAPI TestClient 依赖弃用警告，不影响计算结果，后续依赖升级时处理。
