# DataWork 0.4.7 MANOVA 固定方法与必要设置修复审查

## 问题

旧界面同时使用“MANOVA 可含 1–3 个因素”和 `factor_model_order` 参数。前端缺失项、预检初筛和计划模型可能读取不同值，导致用户已选择因素后仍显示缺少必要设置。最小/最大组合阶数也使工作流难以理解。

## 修复

- 新建分析拆分为 `oneway_manova`、`twoway_manova`、`threeway_manova`；
- 三个方法分别固定恰好 1、2、3 个分类因素；
- MANOVA 不再暴露 `factor_model_order`；
- 固定方法的组合区只显示“方法固定为 N 个因素/模型”，不显示最小/最大阶数；
- 超额因素必须确认后才按 `C(n,k)` 展开；
- 旧 `manova` 计划自动迁移；
- 修复交互效应名称还原中的子串重复替换。

## 验证

- 单因素、双因素、三因素 MANOVA 在完整选择后预检均可执行；
- 缺少因素时提示“恰好需要 N 个固定/分类因素”；
- 双因素 MANOVA 选择第三个候选因素时，未确认会拒绝，确认后生成 A×B、A×C、B×C；
- 旧统一 MANOVA 保存阶数 2 时迁移为双因素 MANOVA；
- 特殊因素名 `MF1`、`MF2` 的显著交互可正常进入简单效应；
- 125 项单元测试和 39 项集成/端到端测试通过，共 164 项；
- 46 个可见可执行方法与 46 个执行器一一对应；
- Vue TypeScript 和 Vite 生产构建通过。
