# DataWork 0.4.9 普通用户易用性与参数层级优化

## 1. 设计目标

普通用户默认只需完成三件事：

1. 选择要回答的统计问题；
2. 选择变量角色；
3. 使用推荐设置执行分析。

专业参数继续完整保留，但不在普通流程中一次性展开，避免用户因为参数数量过多而误选、漏选或把诊断选项误认为主分析必须项。

## 2. 简洁模式（默认）

简洁模式只展示：

- 方法和用途说明；
- 必需变量角色；
- 当前推荐设置摘要；
- 每个方法最多 1–2 个常用参数；
- 参数的一句话解释和推荐理由。

界面摘要使用“显著性标准：0.05”等普通语言，不强迫用户先理解符号 `α`。

## 3. 默认参数策略

### 3.1 两组比较

- 独立组默认推荐 Welch t 检验，因为不强制两组方差相同；
- 配对数据使用配对 t 或 Wilcoxon，取决于研究设计和差值分布；
- 备择方向、精确算法等保留在专业模式。

### 3.2 单因素多组比较

- 普通 ANOVA 事后比较默认选择“自动”；
- 方差齐时使用 Tukey–Kramer；
- 方差不齐时使用 Games–Howell；
- 用户仍可在常用设置中选择 Duncan、Dunnett 或不比较。

### 3.3 双/三因素 ANOVA 与 MANOVA

- 默认事后比较为 Tukey；
- 显著交互优先进入校正后的简单效应，不直接把边际主效应字母组作为主要结论；
- Dunnett 只有被选择时才显示对照水平输入框；
- Duncan 明确标为宽松方法和补充用途。

### 3.4 MANOVA

- 默认主要判据和输出判据均为 Pillai；
- Wilks、Hotelling–Lawley、Roy 和“全部四种”保留在专业模式；
- Box's M、Mardia、相关冗余、单变量跟进范围与平方和类型默认隐藏，但仍按推荐值执行并进入报告。

## 4. 事后检验选项的一句话解释

常用设置中的每个选项现在直接显示短说明：

| 方法 | 普通用户说明 |
|---|---|
| 自动 | 推荐；根据方差齐性在 Tukey 和 Games–Howell 间选择 |
| Tukey | 常规全组两两比较首选，控制整体误报风险 |
| Games–Howell | 方差不齐或样本量差异明显时使用 |
| Duncan | 较宽松，农业领域常见，但假阳性风险更高 |
| Dunnett | 只比较各处理组与指定对照 |
| Holm | 逐步校正，通常比 Bonferroni 更有检验效能 |
| Bonferroni | 简单保守，比较很多时可能不易检出差异 |
| FDR-BH | 更适合探索性筛选 |
| 不执行 | 只报告总体检验，不定位具体组间差异 |

低频选项在简洁模式中不占据空间，切换专业模式后可查看全部。

## 5. 专业模式

专业模式保留所有原有能力，包括：

- 显著性水平；
- 备择方向；
- Type I/II/III 平方和；
- 精确、渐近、置换和 Monte Carlo 设置；
- 诊断图；
- EMM；
- 多重比较校正；
- MixedLM 优化器、REML、最大迭代次数和随机斜率；
- MANOVA 四种判据和诊断；
- 随机种子及其他可复现设置。

切换显示模式不会重置参数。无论参数是否可见，其实际值都会进入 `AnalysisPlan`、预检、执行器、项目保存和报告。

## 6. AI 悬浮窗交互修复

真实浏览器审查发现，八方向缩放样式末尾的通用重置规则会覆盖部分边缘和角落的定位/尺寸，导致某些手柄可见但难以真正拖动。

现已：

- 把通用尺寸重置移动到方向规则之前；
- 将八个命中区域全部放在窗口内部，避免 `contain: paint` 和浏览器缩放裁剪；
- 扩大四边与四角命中区域；
- 保持标题栏拖动、左右停靠、最大化、最小化和状态保存；
- 使用真实 Chromium 验证拖动和右下角缩放后窗口几何确实改变。

## 7. 可用性约束测试

自动测试现在强制：

- 每个方法的普通参数不超过 2 个（阶数专用控制除外）；
- 所有普通参数必须有简短说明；
- 可选普通参数必须给出推荐选项和选项级解释；
- 高级参数仍存在并可进入专业模式；
- 一因素 ANOVA 默认自动，析因 ANOVA/MANOVA 默认 Tukey，MANOVA 默认 Pillai；
- Dunnett 对照输入只在选择 Dunnett 后出现。
