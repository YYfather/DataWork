# DataWork 0.4.1 全交互与全方法审查

## 1. 审查目标

本次审查不只验证统计函数是否返回数值，还验证用户从上传数据到获得报告的完整过程：

1. 数据读取与空白列排除；
2. 方法和变量角色显示；
3. 高级参数默认值及非默认值；
4. 分析前检查；
5. 等待动画与重复提交保护；
6. 单次、批量和因素组合执行；
7. 结果失效与结果展示；
8. 错误提示、重试和字段定位；
9. 项目工作区保存、运行和报告；
10. AI 助手抽屉与设置交互；
11. HTTP API 和跨平台桌面外壳契约。

## 2. 方法矩阵

全部 43 种可执行方法均使用代表性合法数据完成：

- 应用服务预检；
- 应用服务执行；
- CSV 上传后的 `/api/preflight`；
- CSV 上传后的 `/api/analyze`；
- 结果类型和基础字段检查。

每种方法还检查了适用的异常场景：

- 缺少因变量、分类因素、协变量、随机因素、对象 ID 或重复因素；
- 数值因变量误选为文本；
- 分类因素只有一个水平；
- 未知高级参数；
- 成功类别不存在；
- 有序水平集合或顺序错误；
- 分层检验暴露变量不是二元；
- 因素组合存在空单元格；
- 批量子任务中因素水平不足。

## 3. 数据变体矩阵

共检查 350 个方法—数据变体：

- 基线合法数据；
- 随机缺失；
- 极小样本；
- 重复第一行；
- 常数分类因素；
- 常数因变量；
- 文本化因变量；
- 含极小子集的批量拆分；
- 同一变量承担冲突角色。

其中 172 个配置在预检后仍满足执行条件，全部成功运行；其余配置均被预检阻止，没有发生预检崩溃，也没有“预检通过、执行失败”。

## 4. 高级参数矩阵

对方法注册表中的选择、布尔、整数和数值参数执行了 100 个非默认变体。修复内容包括：

- `less/greater` 映射为 statsmodels 比例检验所需的 `smaller/larger`；
- 有序回归链接函数映射为正确的 SciPy 分布：
  - logit → logistic；
  - probit → normal；
  - cloglog → Gumbel minimum；
  - loglog → Gumbel maximum；
  - cauchit → Cauchy。

修复后 100 个变体全部执行成功，未产生 RuntimeWarning。

## 5. 数据读取修复

单列 CSV 原先使用自动分隔符探测时，可能把小数点、负号或其他字符误识别为分隔符，使唯一列在清洗时消失。现在只接受逗号、分号、制表符或竖线作为候选分隔符；没有候选符号时按单列文件读取。

空标题、`Unnamed`、全空和仅空格列仍会在数据画像前排除，不进入变量选择、AI 画像或分析。

## 6. 预检增强

后端预检新增或加强：

- 成功类别和参考类别存在性；
- 有序水平完整性、唯一性和顺序；
- CMH/Breslow–Day 二元暴露与有效 2×2 分层表；
- 配对分类变量类别集合一致性；
- Cochran Q 至少存在对象内变化；
- 回归样本量、参数数量和分离风险；
- MANOVA 设计矩阵秩；
- 因素设计空单元格和单例单元格；
- 每个批量子任务的完整方法级校验。

当所有批量子任务均无效时阻止运行；只有部分无效时提前显示具体批次和原因，允许其余任务继续并在合并结果中保留状态。

## 7. 等待状态

以下操作均显示等待动画、阶段标题和简短说明，并禁止重复点击：

- 读取并检查数据；
- 分析前检查；
- 执行统计分析；
- 创建或加载项目；
- 上传工作区数据集；
- 保存分析计划；
- 运行工作区计划；
- 生成报告；
- AI 说明、结果解读、模型探测和连接测试。

全局长任务使用遮罩；预检和 AI 使用局部动画。动画遵循 `prefers-reduced-motion`，减少动画偏好的用户不会被强制播放持续动画。

## 8. 错误引导

错误响应统一包含错误代码、用户可读说明和可选细节。界面提供：

- 重新读取或重新执行；
- 关闭提示；
- 返回变量或参数区域；
- 高亮需要修正的区域；
- 保留当前文件、变量角色和高级参数；
- 防止旧结果继续显示为当前结果。

服务器内部异常返回安全的通用错误，不把堆栈、文件路径或内部实现细节暴露给普通用户。

## 9. 浏览器交互审查

使用生产 Vue 静态资源和 FastAPI TestClient 完成无头浏览器审查：

- 即时文件上传和读取等待；
- 空白列排除提示；
- 预检等待、确认和分析等待；
- 结果页面出现；
- 修改方法后旧结果消失；
- 不完整计划弹窗、返回与字段定位；
- 结构化错误、重试和关闭；
- AI 抽屉滚动到底部后关闭按钮仍可见；
- 项目、数据集、计划、运行和报告链路；
- 所有按钮具有可访问名称；
- 无 JavaScript page error。

运行：

```bash
python scripts/audit_web_interactions.py
```
