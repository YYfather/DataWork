# DataWork 0.4.9 · Web 部署分支

本分支对应 `DataWork-v0.4.9-网站部署版本`，用于服务器/网站迁移，不是通用开发源码。

- `DataWork服务/`：Linux/宝塔运行服务；运行时数据写入其中的 `data/`，该目录不纳入版本控制。
- `主页完整副本/`：网站部署副本。
- `主页增量覆盖/`：现有主页的 `/datework` 入口增量文件。
- `宝塔配置/`：Nginx 反向代理和部署检查材料。
- `SHA256SUMS.txt`：当前分支文件完整性清单。

安全边界：生产工作区密码摘要、API 密钥、用户数据库、上传数据和报告不提交到仓库。部署后请在服务器本机运行 `DataWork服务/设置工作区密码.sh` 生成真实的 `data/workspace_auth.json`，并按部署说明设置权限。

开始部署前请阅读 [请先阅读.txt](请先阅读.txt) 和 [DataWork服务/宝塔面板部署说明.txt](DataWork服务/宝塔面板部署说明.txt)。
