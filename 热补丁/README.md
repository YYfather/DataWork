# DataWork 服务器热补丁索引

本目录只保留可审计、可安装、可回滚的热补丁源码目录。当前全部补丁均为
`unreleased`；ZIP 与 `.zip.sha256` 不是仓库资产，只能在批准正式发布时临时生成。

## 安装路径

- 原始 0.4.9 或 1.0.0 可直接使用 `0.4.9或1.0.0 -> 1.5.0` 补丁。
- `0.4.9 -> 0.4.9` 是同版本功能补丁；仅在继续停留于 0.4.9 时单独使用。
- `1.5.0 -> 1.5.0` 是可选网页公告；若立即升级 1.7.0，无需安装该公告。
- 升级 1.7.0 前必须处于经清单识别的 1.5.0 服务器基线；不得从 0.4.9、1.0.0 或未留档的 1.6 副本直接应用。

每次安装前先在补丁目录执行 `sha256sum -c SHA256SUMS.txt`，再按包内说明运行应用脚本。
应用脚本会验证服务器基线、备份被替换文件、校验目标哈希，并保留对应回滚入口。

## 目录契约

每套补丁保留以下审计材料：

- `payload/`：只包含服务器程序文件和生产静态资源，不包含用户数据或密钥；
- `PATCH_INFO.json`：基线、目标、功能边界和未发布状态；
- `PACKAGE_VERIFICATION.json`：目录级验证结论；
- `SHA256SUMS.txt`：补丁目录内部完整性清单；
- 基线/目标清单、删除清单、安装脚本、回滚脚本和安装说明。

完整服务器部署版位于本分支的 `DataWork服务/`，当前版本为 1.7.0。通用开发源码、
桌面外壳、测试集和发布构建器只属于 `main` 源码分支，不得复制到服务器补丁中。
