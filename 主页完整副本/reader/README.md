# 一隅书房 / Reader

这是在线阅读器，支持 PDF 书架管理与阅读。

## 运行

- 生产环境：将本目录部署到支持 PHP 的 Web 根目录，访问 `/reader/`。
- 本地预览：在 Web 根目录运行 `node reader/dev-server.js`，访问 `http://127.0.0.1:8765/reader/`。

`api.php` 只读扫描 `source/`，按 `source/系列名/*.pdf` 的结构组织书库。本地预览服务器提供等价的只读接口。

## 主要优化

- 以阅读画布为核心，降低工具栏和主题切换的视觉噪音。
- 中文自然排序、系列折叠、书名/系列搜索、最近阅读入口。
- 每本书独立保存页码与阅读进度，自动恢复。
- 单页与连续滚动模式，适应宽度、缩放、全屏与键盘快捷键。
- 移动端书库抽屉、紧凑翻页控件和安全区适配。
- PDF 按需渲染、连续模式预加载窗口、加载与错误恢复状态。
