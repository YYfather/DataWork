DataWork macOS 命令包（中文说明）
================================

本包不是 DMG 安装程序，不包含 macOS Developer ID 签名，适合个人使用和测试。

一、系统要求
------------
1. macOS 11 或更高版本；
2. Python 3.11 或更高版本；
3. 首次安装依赖时需要访问互联网。

二、安装与启动
--------------
1. 将 ZIP 完整解压到一个固定目录；
2. 双击“安装 DataWork.command”，等待依赖安装完成；
3. 以后双击“启动 DataWork.command”即可使用；
4. 默认浏览器地址为 http://127.0.0.1:8765；
5. 关闭启动命令所在的终端窗口即可停止服务。

三、macOS 安全提示
------------------
由于本命令包没有付费 Developer ID 签名，macOS 可能阻止首次运行。
请在 Finder 中按住 Control 键点击命令文件，选择“打开”，再确认运行。

如果命令文件没有执行权限，请打开“终端”，进入解压目录并执行：

chmod +x "安装 DataWork.command" "启动 DataWork.command"

四、数据位置
------------
用户项目默认保存在：

~/Library/Application Support/DataWork

卸载程序时，请先备份该目录中的项目、上传文件和报告。

五、安全说明
------------
本命令包默认只监听 127.0.0.1，不向局域网或互联网开放。
不要将启动参数改为 0.0.0.0，除非已经配置身份验证、HTTPS 和防火墙。
